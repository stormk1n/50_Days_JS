# 🚀 50 Days JS

A 50-day journey to improve my JavaScript skills by building projects, solving challenges, and learning JavaScript concepts through practice.

## 📖 About

**50 Days JS** is a personal coding challenge where I spend 50 days learning and practicing JavaScript.

Each day focuses on a specific concept, challenge, or project. The goal is to become more confident with JavaScript by writing code consistently and building things along the way.

## 🎯 Goals

* Strengthen my JavaScript fundamentals
* Improve problem-solving skills
* Learn modern JavaScript
* Build real-world projects
* Practice writing clean and maintainable code
* Stay consistent for 50 days

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub
